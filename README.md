# HackNC2026
Welcome to ctrl + alt + study! In this desktop application there are a multitude of different programs that each have a unique function catered towards students. We understand that amidst the hustle and bustle of college life, there needs to be something that can make studying more productive while also making breaks more rewarding rather than getting trapped into the easily accessible short dopamine bursts that social media provides. This why we created ctrl + alt + study!, to connect college students with the beautiful environment surrounding them while utilizing a playful and nostalgic Frutiger Aero theme. Below you will find the main components of our desktop application:

1. Focus.exe:
   Focus.exe is a program that helps students do their schoolwork through the Pomodoro Method. This popular time management method asks you to alternate pomodoros — focused work sessions — with frequent short breaks to promote sustained concentration and stave off mental fatigue. Our program allows the user to create a focus session in the Focus Garden paired with short phrases of encouragement to boost morale. It also provides a study plan which allows user to purposefully plan out their pomodoros.

2. Explore.exe:
   We understand that everyone prefers a different studying environment, that's why we created Explore.exe. Through implementing a Campus Explorer of UNC Chapel Hill, users can virtually explore different study areas they otherwise may not have known about. With different types of environment such as, "Outdoor", "Library", or "Campus", users are sure to be able to find their new study habitat that best suits their individual studying needs.

3. Nature.fm:
   Of course a proper focus session requires the perfect ambiance. Introducing Nature.fm - a program that brings a little calm, on demand, through peaceful Frutiger Aero inspired sounds. This program is sure to immerse the user into a soundscape that fits the right studying/break vibe.

4. TouchGrass.exe:
   Need meaningful breaks that actually refreshes your mind? TouchGrass.exe is the perfect place to do so. TouchGrass.exe provides outdoor quests to do at UNC Chapel Hill. By completing quests the user accumulates points that goes toward their "Garden Score". Every 20 points a user accumulates they gain a sprout which unlocks a fun fact about the plants at UNC Chapel Hill. Through this quest reward system users are able to explore UNC Chapel Hill's natural stunning scenery while also learning the history behind it.

5. Weather.exe:
   For any outdoor adventure, it is important to be prepared. Therefore, we created Weather.exe in order for the user to be aware of the weather. It provides all the important weather information such as the temperature, UV index, Rain(next 3 hrs), and any wind. Weather.exe provides this information for a variety of places across UNC Chapel Hill's campus.

6. Sprout.exe:
   Studying can often get very lonely very fast, which is why we created Sprout.exe! Sprout.exe is an interactive chat bot that uses user information from ctrl + alt + study! to provide carefully curated responses. Sprout.exe is connected to all programs mentioned above to help users decide on what outdoor quests to do to deciding on a study environment that best suits their needs.

7. Screensaver.exe:
  For a bit of classic Frutiger Aero nostalgia, Screensaver.exe provides just that. Featuring a fish bouncing across the screen in a cosmic aquarium in a galaxy far away, it encourages users to patiently wait for the perfect moment when the fish hits a corner exactly right.
