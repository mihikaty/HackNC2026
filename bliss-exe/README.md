# ctrl + alt + study! (bliss-exe)

A Frutiger Aero desktop for students, built with Next.js. It has seven small programs (Focus, Explore, Nature.fm, TouchGrass, Weather, Sprout, and a screensaver) and a companion, **Sprout**, who chats in the browser and over iMessage. See the [project README](../README.md) for what each program does.

This folder is the website. `agent/` is a separate Node program that runs Sprout over iMessage.

## Quick start

Requirements: Node 20 or newer (developed on Node 22) and npm.

```bash
cd bliss-exe
npm install
cp .env.example .env.local   # then fill in the keys (see below)
npm run dev                  # http://localhost:3000
```

After pulling new changes, run `npm install` again. New dependencies (for example the Explore map) won't exist on your machine until you do.

## What needs which key

The site works without any keys. Features switch on as you add them.

| Feature | Needs | Where |
| --- | --- | --- |
| Sprout chat and every "Ask Sprout" button | `GEMINI_API_KEY` | `bliss-exe/.env.local` |
| Weather soundscapes in Nature.fm | `ELEVENLABS_API_KEY` (Sound Effects permission) | `bliss-exe/.env.local` |
| Sprout over iMessage | `PHOTON_PROJECT_ID`, `PHOTON_PROJECT_SECRET`, `GEMINI_API_KEY` | `bliss-exe/agent/.env` |
| Voice notes from Sprout | `ELEVENLABS_API_KEY` (Text to Speech permission) | `bliss-exe/agent/.env` |
| Weather, Explore, TouchGrass, Focus | nothing (weather uses the free Open-Meteo service) | |

Two details that trip people up:

- The website reads `.env.local`. The agent reads `.env` (not `.env.local`).
- Restart the dev server after editing `.env.local`, and restart the agent after editing its code or `.env`.

Real keys must never be committed. `.env*` is git-ignored, and only the `.env.example` templates are tracked.

## Running Sprout over iMessage

```bash
cd bliss-exe/agent
npm install
cp .env.example .env    # fill in the keys
npm start
```

You should see `Sprout is connected and listening for messages.` and `Sprout notify endpoint on http://127.0.0.1:8787/notify`.

Run only one copy of the agent per Photon project. If two copies run (for example on a teammate's laptop), every text gets two replies.

### Texts and voice notes from the website

In **Sprout.exe**, open "Texts from Sprout" and enter your number (`+19195551234`). The number stays in your browser. With it on, and the agent running on the same machine:

- Starting and finishing a Focus session texts you; the finish text also comes as a voice note.
- Sending a study spot to Sprout from Explore texts you only if the weather is worth a warning (rain, heat, cold, wind, high UV, thunder).
- **Read to me** on a TouchGrass quest texts you the quest and speaks it as a voice note.

### Voice notes

Sprout follows each reply with a voice note when `ELEVENLABS_API_KEY` is set in `agent/.env`. It is skipped for long replies and never delays or breaks the text reply. Set `SPROUT_VOICE=off` to turn it off, or `ELEVENLABS_VOICE_ID` to change the voice.

## Weather soundscapes

Nature.fm has a "Weather ambience" panel. It checks the real weather at a study spot and plays a matching looping sound generated by ElevenLabs. There are nine weather categories, and each sound is generated once and cached in `.soundscape-cache/` (git-ignored), so it uses very few credits.

## Project layout

```
bliss-exe/
  app/
    page.tsx                  desktop, windows, taskbar
    components/               one folder per program (focus, explore, nature, ...)
    components/sprout/        chat window, "Ask Sprout" button, shared chat state
    api/sprout/               chat route (Gemini)
    api/sprout/text/          texts and voice notes (calls the agent)
    api/weather/              weather and verdict for a study spot
    api/soundscape/           weather-matched sound (ElevenLabs)
  lib/weather.ts              Open-Meteo lookup, rain/heat/UV rules, soundscape picker
  lib/quests.ts               TouchGrass quests (shared with the server)
  agent/                      Sprout over iMessage (Photon Spectrum)
```

Change the weather thresholds (heat, cold, wind, rain chance, UV) at the top of `lib/weather.ts`.

## Troubleshooting

- **A red "Module not found" error after pulling:** run `npm install`.
- **The page looks unstyled or old:** hard reload (Cmd+Shift+R).
- **"Sprout is tangled" replies:** `GEMINI_API_KEY` is missing in `.env.local`, or the dev server needs a restart.
- **No texts or voice notes:** the agent must be running on the same machine, and a number must be saved in Sprout.exe.
- **Soundscape says it needs a key:** add `ELEVENLABS_API_KEY` to `.env.local` and restart `npm run dev`.

## Known limits

- Texts and voice notes need the agent on the same machine as the website, so they won't work from a hosted deployment as it stands.
- Cached soundscapes are saved to local disk, which a hosted deployment wouldn't keep.
- This project uses a newer Next.js than most documentation covers; see `AGENTS.md`.
